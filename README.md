# Логарифмы без стресса — первая рабочая версия

Статический сайт для GitHub Pages. Сборка, аккаунты учеников и сервер не нужны.

## Открыть на компьютере

Откройте `index.html` двойным щелчком в Chrome, Edge или Firefox. Все скрипты, стили и шрифты KaTeX включены в папку; интернет не требуется. Для надёжного постоянного хранения прогресса используйте опубликованный сайт: поведение localStorage при открытии через `file:` зависит от браузера. Сохранения локальной и опубликованной версии раздельные.

## Опубликовать на GitHub Pages

1. Создайте репозиторий, например `logarithms-without-stress`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html` должен лежать прямо в корне. Обязательно загрузите папку `vendor` целиком, включая `vendor/katex/fonts`. Файл `.nojekyll` тоже включён.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. В **Branch** выберите **main** и **/ (root)**, затем **Save**.
6. Дождитесь успешного завершения публикации во вкладке **Actions**. Адрес появится в **Settings → Pages**: `https://ВАШ-ЛОГИН.github.io/logarithms-without-stress/`.
7. Проверьте главную, тренировку и перезагрузку страницы занятия. Все ссылки относительные; разделы используют `#`, поэтому сайт работает в подпапке репозитория.

Официальная инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что работает

- Главная с тремя маршрутами, семью разделами и локальным прогрессом.
- «Определение логарифма»: три ступени, десять семейств задач.
- Смешанные серии каждой ступени и отдельные серии каждого семейства: по 10 случайных задач.
- Для каждой серии доступны тренировка с тремя подсказками и контрольная без подсказок.
- Ответ числом, дробью, десятичным числом через точку или запятую; предпросмотр и кнопки «минус» и «дробная черта». Там, где требуется, — выбор варианта.
- Проверка, объяснение через определение, разбор всех задач и отдельный повтор ошибок.
- Возобновление одной незавершённой работы: ответы, текущая задача, использованные подсказки. Начало другой серии заменяет незавершённую работу.
- Лучшие результаты смешанных контрольных сохраняются отдельно по маршрутам, независимо от последних 30 подробных результатов.
- Остальные шесть разделов помечены «Пока не реализован».

Маршруты дают разные рекомендации и отдельную статистику. В первой версии банк первого раздела общий для всех маршрутов, все ступени открыты сразу.

## Прогресс

Прогресс первого раздела — сумма лучших результатов **смешанных** контрольных трёх ступеней, делённая на 30. Контрольные отдельного навыка, тренировки и повтор ошибок его не увеличивают. Освоение ступени — не менее 8/10, при этом 100% означает 10/10 на всех трёх смешанных контрольных. Разбор хранит результат первой проверки; тренировочные ответы после неё не меняются.

Данные хранятся только в localStorage данного браузера и адреса сайта (`logs-without-stress:v1`). Синхронизации между устройствами нет. Очистка данных сайта удалит прогресс. Если хранилище недоступно, сайт предупреждает об этом и позволяет заниматься в текущей вкладке.

## Карта D01–D10 этой версии

| Код | Ступень | Навык |
| --- | --- | --- |
| D01 | 1 | Вычислить логарифм с целым положительным ответом |
| D02 | 1 | Ноль и отрицательные показатели |
| D03 | 2 | Логарифм с обратным основанием |
| D04 | 2 | Дробный ответ, квадратный или кубический корень в аргументе |
| D05 | 2 | Найти аргумент |
| D06 | 2 | Найти основание с учётом его допустимости |
| D07 | 1 | Найти показатель в показательной записи |
| D08 | 3 | Перевести логарифмическое равенство в показательное |
| D09 | 3 | Проверить существование логарифма |
| D10 | 3 | Применить определение к обратным операциям |

**Граница восстановленного контекста:** вложенные CSS и три скриншота получены из указанной беседы. Более ранняя таблица семейств и числовых ограничений не присутствует в доступной истории. Поэтому эта карта — явная реализация первой версии, а не подтверждённое воспроизведение прежней таблицы.

Консервативный банк использует основания 2, 10, 1/2 и 1/10. Степени 2 ограничены по модулю показателя числом 10, степени 10 — числом 4. В D04 берутся квадратные/кубические корни этих степеней. Другие допустимые основания пока не добавлены, чтобы не расширять неизвестные ограничения. В D09 встречаются также 0, 1 и −2 как **намеренно недопустимые** основания для проверки существования. В вариантах D08 ложные равенства не являются предлагаемыми вычислениями.

## Оформление и файлы

- `globals.css` — исходный файл диагностик, сохранён без изменений.
- `trainer.css` — адаптивная компоновка тренажёра и отдельные переопределения.
- `engine.js` — генераторы и проверка числовых ответов, без `eval` для пользовательского ввода.
- `app.js` — экраны, навигация, занятия, результаты и сохранение.
- `vendor/katex` — KaTeX 0.16.22, стили, шрифты и лицензия MIT. Локальное подключение: https://katex.org/docs/browser

Палитра перенесена из CSS точно: milk `#fffdf8`, ink `#302b3b`, violet `#8d72cf`, violet-dark `#6f55b4`, violet-soft `#eee8fb`, blue `#ddecf5`, pink `#f7dfe9`. Заголовки — Georgia; интерфейс — Segoe UI; декоративный акцент — Segoe Print.

## Проверка

Математический тест без установки зависимостей (при наличии Node.js):

```sh
node engine.test.cjs
```

Он проверяет 15 000 задач, независимые числовые тождества, ограничения, варианты выбора, разбор дробей и формулы KaTeX. Проведены также автоматические сценарии интерфейса и ручная проверка в браузере, в том числе на ширине 390 px. Подробности — в приложенном отчёте `Проверка.md` рядом с архивом. Для запуска дополнительных сценариев разработчиком: `npm install`, затем `npm run test:ui`; для работы самого сайта это не нужно.

Публикация в аккаунт GitHub в этой задаче не выполнялась: готовые файлы предназначены для загрузки в выбранный вами репозиторий.
